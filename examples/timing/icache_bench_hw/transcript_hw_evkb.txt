icache_bench_hw -- HARDWARE, MIMXRT1170-EVKB (NEW-36)
================================================================================
2026-09-05.  teensy-cores 2304743 (I-cache enabled in ResetHandler), M2Radio
7c91cca.  Procedure: LinkServer flash load -> verify (File matches flash) ->
tools/rt1170-console.py attached -> SW4.  Default build (Sbc.cpp.obj routed to
FLASH): THREE boots.  build-sbc-itcm (-DICACHE_BENCH_SBC_ITCM=ON): ONE boot,
the reference cell.

READINGS
  ccr_reset=0x00040200  -> the boot ROM hands over with IC=0, DC=0 (BP and
                           STKALIGN set): the CM7 had been running with NO
                           instruction cache, now a reading rather than an inference
  ccr_now=0x00060200    -> IC set by ResetHandler
  clidr=0x09000003 ccsidr_i=0xf03fe009 -> isize_kb=32 ways=2 line_b=32 (RT1176 datasheet: 32 KB, 2-way, 32 B)
  calls  flash off->on 192.3 -> 8.3 cyc/call = 23.0x ; cached flash == ITCM (8.3) ; ITCM off==on (TCM control)
  crc    9.0 cyc/byte in every cell = 1.0x (the ~20-byte inner loop lives in the FlexSPI AHB prefetch buffer)
  sbc    flash off->on 1106 -> 187 us/frame = 5.9x ; ITCM 125 us/frame ; cached flash = 1.5x ITCM ;
         realtime_x on = 15.5 (ITCM 23.2, uncached flash 2.6)
  witnesses: every wit_match=1 on every boot; sbc_crc=0x6c24f764 identical across QEMU, the flash
         build and the ITCM build; flen=119
  boots: 1/2/3 agree within 0.05% on every min, bit-identically on every witness and decode
         (boot 3's derived us/frame_off rounds to 1107 rather than 1106 -- the underlying
         min_cyc/frame values are 1102528.0 / 1102290.7 / 1102710.9, a 0.038% spread)
PREDICTIONS (spec "What the code predicts") -- HELD / REFUTED:
  ROM leaves IC=0: HELD (0x00040200)
  32 KB 2-way 32 B: HELD
  calls >= 10x, cached flash within ~1.5x of ITCM: HELD (23.0x; 1.0x)
  sbc within ~2x of ITCM, well inside 2.902 ms: HELD (187 vs 125 us = 1.5x; realtime_x 15.5)
NOT PREDICTED, MEASURED:
  crc 1.0x -- icache=off is "AHB-buffered", not "unbuffered"; a 20-byte loop never missed
  uncached calls ~0.19 us/call here vs NEW-33's 5-30 us/call in acid_box: this chain is 1 KB of
  contiguous code; the application's flash-resident chain is tens of KB interleaved with LVGL.
  Everything here fits the 32 KB cache -- every speedup above is a BEST CASE; the application
  number is the acid_box LOOPSTAT A/B (transcript_hw_evkb_bt.txt there).
FOLLOW-ON: realtime_x_on 15.5 >= 5 -> NEW-37 filed (acid_box M2_BT_OUT ITCM routing).
